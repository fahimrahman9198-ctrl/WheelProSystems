# WheelPro Systems — final logo kit

Fitment mark + Mona Sans wordmark (WheelPro Bold / Systems Light). Figma source: "Logo — Final" page in *WheelPro Logo Redesign*.

| Folder | What's inside |
|---|---|
| `svg/` | Masters (`wheelpro-horizontal`, `-stacked`, `-symbol`, `-symbol-small`, `-wordmark`) and their black / white / Torque Blue versions, plus square, favicon and app-icon SVGs |
| `png/` | PNG exports: lockups at 1600 px, symbol at 64 / 256 / 1024 px |
| `web/` | `favicon.ico`, `favicon.svg`, 16/32/48 px favicons, `apple-touch-icon.png`, 192/512 px and maskable icons, `site.webmanifest`, `head-snippet.html` |
| `board/` | Presentation with mockups (`board.html`, `slides/`) |
| `GUIDELINES.md` | Clear space, minimum sizes, colours, typography, don'ts |

Use `wheelpro-horizontal.svg` by default, `wheelpro-stacked.svg` for square spaces, and `wheelpro-symbol.svg` (or `-small` under 32 px) on its own.
